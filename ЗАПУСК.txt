 ИНСТРУКЦИЯ ПО ЗАПУСКУ БОТА
═══════════════════════════════════════════════

1. ПОЛУЧИТЬ ТОКЕН БОТА
   ─────────────────────────────────────────────
   • Напишите @BotFather в Telegram
   • Команда: /newbot
   • Введите название и username бота
   • Скопируйте токен (вида 123456:ABC-DEF...)

2. ВСТАВИТЬ ТОКЕН В КОД
   ─────────────────────────────────────────────
   Откройте файл config.py и замените:
       BOT_TOKEN = "ВСТАВЬТЕ_ВАШ_ТОКЕН_СЮДА"
   на ваш реальный токен:
       BOT_TOKEN = "123456789:ABCdef..."

3. УСТАНОВИТЬ ЗАВИСИМОСТИ (один раз)
   ─────────────────────────────────────────────
   Откройте PowerShell или командную строку в
   папке salon_bot и выполните:

       pip install -r requirements.txt

4. ЗАПУСТИТЬ БОТА
   ─────────────────────────────────────────────
       python bot.py

═══════════════════════════════════════════════
 КАК ПОЛЬЗОВАТЬСЯ БОТОМ
═══════════════════════════════════════════════

ДЛЯ МАСТЕРА:
  1. Напишите /start
  2. Нажмите «Я мастер»
  3. Введите имя и выберите тип услуги
  4. Используйте кнопки меню:
     • 📅 Добавить слоты — выберите дату и время
     • 📋 Мой график — все слоты (занятые и свободные)
     • 👥 Клиенты — список записанных клиентов
     • ⚙️ Настройки — изменить профиль

ДЛЯ КЛИЕНТА:
  1. Напишите /start
  2. Нажмите «Я клиент»
  3. Выберите тип услуги (тату, маникюр, и т.д.)
  4. Выберите мастера
  5. Введите имя и телефон
  6. Выберите свободное время — готово!

УВЕДОМЛЕНИЯ:
  Мастер получит сообщение в Telegram сразу
  после того как клиент запишется.
